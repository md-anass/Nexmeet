# Future Meeting UI Goals

## Waiting room

Design a polished request panel matching the navy, cyan, and purple brand:
- Clear pending count/badge, participant initials and display names.
- Prominent Admit and secondary Reject actions.
- Per-participant processing and admitted/rejected transition feedback.
- Scrollable multiple-request layout and responsive mobile presentation.
- Future Admit all action, with server authorization reviewed before implementation.
- Unobtrusive new-request notifications and accessible focus states.
- Compact conferencing interaction instead of a large debug-style floating card.

## Raise hand

Retain premium raised-hand indicator redesign as a future visual task.

## Password protection

- Premium password-protected meeting indicator.
- Polished password entry screen with show/hide control.
- Accessible focus and error states.
- Mobile-responsive password gate.
- NexMeet security iconography.

These are design goals only; no new functionality is implemented here.
